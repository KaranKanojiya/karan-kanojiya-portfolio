# Specification

## Summary
**Goal:** Build a static single-page personal portfolio website for Karan Kanojiya with a dark, minimal developer aesthetic.

**Planned changes:**
- Create a sticky top navigation bar with smooth-scroll links to Hero, Skills, Experience, Education, and Contact sections
- Build a Hero section with profile avatar, name "Karan Kanojiya", tagline "Senior Software Engineer", summary paragraph, and GitHub/LinkedIn icon buttons
- Build a Skills section with four grouped categories (Languages, Databases, DevOps & Cloud, Frameworks) rendered as teal-accented badge/chip tags
- Build a vertical timeline Experience section with three roles (Autodesk, Tricentis, Tata Communications) showing company, role, location, date range, and bullet points
- Build an Education section showing Bachelor of Computer Engineering from MCTs RGIT with courses listed
- Build a Contact/Footer section with GitHub and LinkedIn icon links opening in new tabs
- Apply dark-themed design (near-black background, white/light-grey text, teal/cyan accent color) with subtle fade-in scroll animations and responsive layout

**User-visible outcome:** Visitors can view Karan's portfolio as a polished single-page dark-themed site, navigate between sections via sticky nav, and access his GitHub and LinkedIn profiles directly.
